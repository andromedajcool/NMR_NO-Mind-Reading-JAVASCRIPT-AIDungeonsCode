No mind reading script is just that ... it is to prevent characters from reading your mind during adventures/scenarios. Has it ever happened to you that you type something in as a thought for your character, then all the sudden NPCs around you are suddenly freaking out because your personal thought was a HUGE surprise? 
If you're anything like me that exact situation gets annoying. It can break immersion and make adventures boring...
This script provides an easy way to try and prevent that from happening!
